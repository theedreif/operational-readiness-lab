# Friction Matrix

Friction is controlled variation that forces judgment to become visible.

| Dimension | Baseline | Friction |
|---|---|---|
| Information | Complete | Missing / stale / contradictory |
| Time | Comfortable | Compressed |
| Signal | Obvious | Weak / competing |
| Authority | Clear | Ambiguous / distributed |
| System state | Nominal | Degraded / intermittent |
| Human state | Unloaded | Task-saturated |
| Communication | Clean | Noise / ambiguity / handoff |
| Automation | Correct | Confidently wrong / silent failure |

Use only the minimum friction necessary to expose the target judgment. The purpose is measurement, not theater.
