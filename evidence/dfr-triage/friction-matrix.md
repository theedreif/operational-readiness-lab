# DFR Triage Friction Matrix

Use the minimum friction necessary to expose independent judgment.

| Dimension | Baseline | Friction Injection | What It Tests |
|---|---|---|---|
| Automation | recommendation supported | high-confidence recommendation contradicted by evidence | automation bias / independent review |
| Information | stable details | corrected address or superseded detail | update discipline |
| Signal | obvious | weak or competing cues | discrimination |
| Communication | clean | overlapping or ambiguous information | meaning recovery |
| Context | familiar terminology | local or unfamiliar terminology | contextual uncertainty |
| Severity | tone matches event | calm affect with severe content | content over affect |
| Time | comfortable | late contradiction / compressed decision | revision under pressure |
| Human workload | single task | simultaneous competing cue | attention allocation |

## Constraint

Do not add dramatic friction merely to make a scenario difficult. Each injection must map to the target judgment and telemetry.

## Authority Boundary

No real dispatch priority, emergency response rule, aviation rule, public-safety threshold, or agency procedure is encoded here.
