# ReadyLink Friction Matrix

| Dimension | Baseline | Friction Injection | Judgment Exposed |
|---|---|---|---|
| Time | active incident | incident appears complete but link persists | continued need |
| Handoff | same operator | shift change / ownership transfer | accountability |
| Workload | one event | simultaneous incidents | forgotten share |
| Audience | known recipients | audience becomes uncertain | authorization |
| Scope | one stream | broader organizational scope | proportionality |
| Access | expected control state | weak/absent control in approved test | access judgment |
| Mission | clearly active | ambiguous completion | revoke vs continue |
| Information | obvious sensitivity | sensitivity changes during event | restriction/escalation |

## Constraint

Use only an approved non-sensitive test environment. Do not create public exposure of operational, personal, evidentiary, or protected information for the purpose of testing the instrument.

The purpose is to make judgment visible, not reproduce the harm.
