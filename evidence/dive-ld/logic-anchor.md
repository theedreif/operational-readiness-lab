# Dive-LD Logic Anchor

## Trigger

Expected platform behavior, contact, progress, or mission state is materially degraded, absent, or inconsistent with expectation.

## Filter

Inspect only information available and authorized for the rehearsal:

- mission phase;
- last known state;
- elapsed unresolved time;
- telemetry quality;
- plausible communications degradation;
- recoverability indicators;
- operating-area implications;
- exposure implications;
- available recovery assets;
- competing mission priorities;
- current decision authority.

## Anchor

Experimental state classification:

- **MONITOR** — anomaly exists but evidence supports continued observation within the test boundary;
- **RECOVER** — the test's authoritative rule requires recovery action;
- **ABORT / CONTAIN** — mission continuation is no longer supported by the test rule;
- **ESCALATE** — authority, exposure, or uncertainty exceeds the operator's experimental boundary.

Actual operational thresholds and actions are:

**UNKNOWN / REQUIRES AUTHORITATIVE VERIFICATION**
