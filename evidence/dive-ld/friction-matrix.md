# Dive-LD Friction Matrix

| Dimension | Baseline | Friction Injection | Judgment Exposed |
|---|---|---|---|
| Contact | nominal | intermittent / lost | state classification |
| Telemetry | coherent | incomplete / conflicting | uncertainty handling |
| Time | comfortable | unresolved state persists | escalation timing |
| Handoff | same watch | shift/watch transfer | continuity |
| Recoverability | obvious | uncertain / changing | recovery judgment |
| Authority | clear | distributed / unavailable | escalation |
| Mission | single priority | competing mission demand | prioritization |
| Exposure | low consequence | exposure implications increase | containment |
| System state | known fault | ambiguous degradation | discrimination |

## Constraint

Use synthetic mission data or an approved test platform/environment. Do not invent classified procedures or recreate unsafe maritime conditions.

Friction exists to expose judgment, not to dramatize the event.
