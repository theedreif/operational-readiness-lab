# Silent Churn Friction Matrix

| Dimension | Baseline | Friction Injection | Judgment Exposed |
|---|---|---|---|
| Headline metrics | green | remain green while behavior changes | lagging-indicator dependence |
| Response | normal | progressively slower | weak-signal detection |
| Meetings | stable | reschedules / lower attendance | pattern recognition |
| Stakeholders | engaged | champion disappears / role changes | relationship interpretation |
| Usage | healthy | flat or subtly declining | trend discrimination |
| Notes | complete | incomplete / reassuring | uncertainty handling |
| History | strong | past renewal success | anchoring |
| Workload | one account | competing healthy-looking accounts | attention allocation |
| Explanation | none | plausible benign reason | premature closure |

## Constraint

Each scenario should contain enough benign variation that "always escalate" is not rewarded. The target is calibrated investigation, not pessimism.
