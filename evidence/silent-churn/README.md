# Silent Churn Evidence Pack v1.0

**Evidence status: ILLUSTRATIVE / PREDECLARED SIMULATION — NOT YET RUN**

> **Golden Thread:** FAILURE MODE → SIGNAL → JUDGMENT → TOOL → FRICTION → EVIDENCE → UPDATE

## Purpose

Test whether the Field System can expose weak-signal judgment in a commercial setting where lagging headline metrics remain healthy while relationship behavior deteriorates.

Unlike ReadyLink and Dive-LD, Silent Churn does not begin with a public incident. It is deliberately a synthetic design case.

## Failure Mode

A renewal account appears healthy in standard reporting while weak behavioral signals indicate emerging relationship risk.

## Hypothesis

**Apparently healthy aggregate metrics can lag meaningful deterioration visible in weaker behavioral signals.**

This is a hypothesis to test, not a validated churn model.

## Judgment Under Test

**Is the account genuinely healthy, or is the dashboard lagging the relationship?**

## Experimental Dispositions

- **MAINTAIN** — evidence does not yet justify a change in account posture;
- **INVESTIGATE** — weak signals warrant additional evidence gathering;
- **ESCALATE** — pattern or consequence requires broader attention;
- **INTERVENE** — predeclared synthetic evidence supports a bounded action.

These are experimental labels, not universal customer-success rules.

## Evidence Boundary

No universal churn threshold, causal predictor, commercial intervention, or field-effectiveness claim is asserted.

> **A green dashboard is not the same thing as a healthy relationship.**
